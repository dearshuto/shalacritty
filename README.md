## About

This repository contains CLI utilities written in Rust.

### asura

A shell multiplexer backend

### shalacritty (obsolete)

A fast, lightweight terminal emulator written in Rust using wgpu.

### shaka

A rewritten version of shalacritty written in Rust using Vulkan directly.

### zazen

A multiplexer frontend inspired by tmux and zellij

## Goal

These tools aim to provide the best developer environment using CLI.

1. Run on multi platforms (Windows, Ubuntu, Mac)
2. Run natively
3. Run fast and lightweight
