# AI Coding Instructions

## 1. Quality Standards

- **Strict Formatting:** For all files that have been　modified, always output
  them after applying `rustfmt`.
- **Test Integrity:** Modifications must pass existing `cargo test`, and if
  necessary, adjust the test code itself to maintain consistency.
- **No Panics:** In Rust code, avoid using `unwrap()` or `expect()` carelessly,
  and handle errors appropriately with `Result` or `Option`.

## 2. Communication

- **Language:** Think in English, then translate the final response into Japanese before committing; comments, explanations, and commit messages should first be formulated in English.
